# 📖 IM Bíblias

## 🌷 Sobre o projeto

O **IM Bíblias** é um projeto de desenvolvimento web criado para uma loja de artigos cristãos, com o objetivo de facilitar a divulgação de produtos, a consulta de preços e a realização de pedidos.

A plataforma apresenta uma interface visual elegante, inspirada em tons de azul-marinho, dourado e elementos amadeirados, buscando proporcionar uma experiência agradável, intuitiva e organizada aos usuários.

O projeto também contempla funcionalidades administrativas para auxiliar no gerenciamento dos produtos e na organização do catálogo da loja.

## ✨ Funcionalidades

- 📚 **Catálogo de produtos:** apresentação de Bíblias, Harpas Cristãs e livros.
- 💰 **Exibição de preços:** consulta dos valores dos produtos disponíveis.
- 📦 **Controle de estoque:** acompanhamento da disponibilidade dos itens.
- 💬 **Pedidos via WhatsApp:** facilidade para entrar em contato e realizar pedidos.
- 🔐 **Autenticação administrativa:** estrutura de acesso à área de administração.
- 🛠️ **Gerenciamento de produtos:** recursos para administrar o catálogo.
- ☁️ **Integração com Supabase:** utilização de serviços de backend para recursos como autenticação e armazenamento de dados.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura das páginas.
- **CSS3** — estilização, layout e identidade visual.
- **JavaScript** — interatividade e funcionalidades da aplicação.
- **Supabase** — serviços de backend e integração com dados.

## 🎨 Identidade visual

O design foi pensado para transmitir elegância e acolhimento, utilizando:

- Azul-marinho para a identidade principal.
- Dourado para os destaques visuais.
- Elementos amadeirados para complementar a identidade da loja.
- Tipografia cuidadosamente selecionada para valorizar a apresentação dos produtos.

## 🚀 Executando o projeto

1. Clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Configure as variáveis e credenciais necessárias para a integração com o Supabase.
4. Execute o projeto conforme a estrutura e as dependências utilizadas.

> **Observação:** nunca compartilhe chaves privadas ou credenciais administrativas no repositório público.
